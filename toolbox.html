플린트의 공구함

플린트호크가 항해에 쓸 만한 도구를 모아둔 공구함입니다.
원자력포, 반중력 순항장치, 대왕문어 퇴치기 등도 있지만 공개하지 않습니다.

Windows 실행 안내
Windows에서 다운로드한 실행 파일이 보안 기능에 의해 차단될 수 있습니다.
실행되지 않는 경우 파일을 마우스 오른쪽 버튼으로 클릭한 후 속성 → 차단 해제 → 적용을 선택하고 다시 실행해 주세요.
Flint 도구는 별도의 코드 서명 인증서를 사용하지 않으므로 알 수 없는 게시자로 표시될 수 있습니다.

플린트 파일 리네이머

여러 파일의 이름을 한 번에 변경하는 도구입니다. 단순한 문자열 치환뿐 아니라 문자열 삭제, 앞·뒤 문자열 추가, 번호 붙이기, 이름과 번호를 이용한 일괄 변경을 지원합니다.

버전: 1.0.0

설명 및 설치 방법

플린트 텍스트 리플레이서

여러 텍스트 파일에 포함된 문자열을 한 번에 찾아 변경하는 도구입니다. 변경 전·후 내용을 자동으로 비교해 보여주며, 실제로 변경되는 파일만 결과 목록에 표시합니다.

버전: 1.0.0
