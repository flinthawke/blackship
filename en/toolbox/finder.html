Flint String Finder

How to Use
Select the search scope (Entire Computer, Drive, or Folder).
Enter the text you want to search for.
If needed, specify file extensions (such as py, md, or txt) and enable Case Sensitive search.
Click Start Search.
Double-click a search result to open the corresponding file instantly.
Key Features
Search the entire computer
Search a specific drive or folder
Search for text within file contents
Filter by file extension (py, md, txt, etc.)
Case-sensitive search
Display the currently scanned file
Show scanned files, processed files, matches found, and errors
Display search progress and elapsed time
Stop an ongoing search
Open files by double-clicking search results
Flint Captain & Seagull progress messages during long searches
