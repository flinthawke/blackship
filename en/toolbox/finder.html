Flint String Finder

Version: 1.3.0

How to Use

Select the search scope. (Entire computer, drive, or folder)

Enter the Search String.

If necessary, set an extension filter (py, md, txt, etc.) and the case-sensitive option.

Click Start Search.

Double-click a result to open the corresponding file directly.

Main Features

Search the entire computer or a specific drive

Search a specific folder

Search for strings within file contents

Display the current file being scanned, number of files scanned, matches found, and errors

Display elapsed time and search progress

Stop an ongoing search

Open files by double-clicking search results

Flint Captain & Seagull progress messages during long searches

Run:

python finder.py

Note: If you are using the executable (EXE) version, you do not need to run the Python command.
