Flint String Finder

Version: 1.3.0

How to Use

  1. Select the search scope. (Entire computer, drive, or folder)
  2. Enter the Search String.
  3. If needed, set an extension filter (py, md, txt, etc.) and the case-sensitive option.
  4. Click Start Search.
  5. Double-click a result to open the corresponding file directly.

Key Features

  • Search the entire computer or a specific drive
  • Search within a specific folder
  • Search for strings inside files
  • Displays the current file being scanned, number of files scanned, matches found, and errors
  • Displays elapsed time and search progress
  • Stop an ongoing search
  • Double-click results to open files
  • Flint Captain & Seagull progress messages during long searches

Run:

python finder.py

Note: If you are using the executable (EXE) version, you do not need to run the python command.
