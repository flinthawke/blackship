Flint Icon Maker

A GUI tool for converting PNG, JPG, WEBP, and BMP images into multi-size ICO files for Windows executables.

How to Use

  1. Click Select Image and choose the image you want to convert into an icon.

  2. Select a square adjustment mode.

  3. Fit Entire Image: Keeps the entire original image visible and adds padding to fill the remaining space.

  4. Center Crop: Fills the square completely and crops part of the edges as needed.

  5. When using Fit Entire Image, enter the padding background color in #RRGGBB format.

  6. Check the preview.

  7. Click Create ICO and choose the save location and file name.

Key Features

  • Supports PNG, JPG, JPEG, WEBP, and BMP images
  • Automatic square adjustment
  • Choose between keeping the entire image or center cropping
  • Customizable padding background color
  • Generates multi-size ICO files at 16, 24, 32, 48, 64, 128, and 256 px
  • Korean and English interface switching
  • Bilingual support for image selection, save dialogs, error messages, and completion notifications
