Flint Text Replacer

A tool for finding and replacing text across multiple text files at once.

It automatically compares the content before and after replacement and displays only the files that will actually be changed in the results list.

How to Use

  1. Click Open Folder and select the folder you want to work with.
  2. Select the files you want to modify from the list.
  3. Enter the Find Text and Replace With values.
  4. Check the preview on the right to see which files will actually be changed and compare the content before and after replacement.
  5. If needed, click Large View to compare the before-and-after content of the selected file in a separate window.
  6. Click Run to apply the replacements.

The preview updates automatically when you enter the text to find or replace. Files with no changes are not shown in the results list. If Backup Original (.bak) is enabled, a .bak backup file is created next to each file before it is modified.

Key Features

  • Batch text replacement across multiple files
  • Automatic before-and-after preview
  • Displays only files that will actually be changed
  • Highlights changed locations
  • Large before-and-after view for selected files
  • Search files in subfolders
  • File extension filtering
  • Optional case-sensitive matching
  • Supports UTF-8, UTF-16, CP949, and EUC-KR encodings
  • Automatic backup of original files

Run:

python replacer.py

Note: If you are using the executable (EXE) version, you do not need to run the Python command.
