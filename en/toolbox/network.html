Flint Network Utility

Version: 1.0.0

### Quick Check

1. Launch the program.
2. Click **`Quick Check`**.
3. When the scan is complete, review the overall diagnosis at the bottom.
4. If needed, click **`Save Log`** to keep a copy of the results.

The Quick Check verifies the following:

- Local IP address
- Default gateway
- 20 pings to the router
- 20 pings to Cloudflare and Google DNS
- DNS lookup
- Packet loss and latency
- Overall network diagnosis

### Continuous Monitoring

Use this feature to detect intermittent internet disconnections.

1. Select the monitoring interval.
2. Click **`Start Monitoring`**.
3. Leave the program running until the issue occurs.
4. Click **`Stop Monitoring`** when you are finished.

The program continuously checks both your router and the external internet connection while keeping track of cumulative failures.

### Trace Route

Click **`Trace Route`** to view the path your connection takes to reach the internet.

### System Requirements

This program uses the Windows **`ping`**, **`route`**, **`nslookup`**, and **`tracert`** commands, so it is available on **Windows only**.
