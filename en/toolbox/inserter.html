Flint Text Inserter

Version: 1.0.0

How to Use

  1. Click Add Files to select individual files, or click Add Folder to select a folder.
  2. When a folder is selected, all supported files in that folder and its subfolders will be added to the list automatically.
  3. Enter the text you want to insert.
  4. Choose whether to insert it at the Beginning or End of each document.
  5. Review the options for Blank Line, Backup, and Duplicate Prevention.
  6. Click Insert to start the process.

Example:
