Flint Text Inserter

Version: 1.2.0

How to Use

  1. Click Add Files to select files directly, or click Add Folder to select a folder.
  2. When a folder is selected, supported files in that folder and its subfolders are automatically added to the list.
  3. Enter the String to Insert.
  4. Select Top of Document or Bottom of Document.
  5. Check the blank line, backup, and duplicate prevention options.
  6. Click Run Insertion.

Example:

<!-- poem -->

# A Heart Turned into Wind

Key Features

  • Insert the same string into multiple files at once
  • Insert at the top or bottom of documents
  • Add all supported files from a folder
  • Search subfolders recursively
  • Optional blank line between the inserted string and document content
  • Automatically skip files that already contain the same string
  • Supports UTF-8, CP949, and EUC-KR encodings
  • Preserves the original line ending format
  • Automatically backs up original files

Supported extensions:

.txt .md .markdown .html .htm .css .js .py .json .yml .yaml

Run:

python inserter.py

Note: If you are using the executable (EXE) version, you do not need to run the python command.
