플린트 파일 리네이머

버전: 1.0.0

사용 방법

  1. 폴더 열기를 눌러 파일이 있는 폴더를 선택합니다.
  2. 이름을 변경할 파일을 선택합니다.
  3. 변경 방식에서 원하는 이름 변경 방식을 선택합니다.
  4. 필요한 문자열이나 번호 설정을 입력합니다.
  5. 오른쪽 미리보기에서 변경될 파일명을 확인합니다.
  6. 선택 파일 이름 바꾸기를 눌러 변경합니다.

변경 방식

  • 찾아 바꾸기: 파일명에서 특정 문자열을 찾아 다른 문자열로 변경
  • 문자열 삭제: 파일명에서 지정한 문자열 삭제
  • 앞에 붙이기: 기존 파일명 앞에 문자열 추가
  • 뒤에 붙이기: 기존 파일명 뒤에 문자열 추가
  • 번호 붙이기: 기존 파일명 뒤에 순번 추가
  • 이름 + 번호: 지정한 기본 이름과 순번으로 파일명 통일

번호를 사용하는 방식에서는 시작 번호와 자릿수를 지정할 수 있습니다.

예시:

photo.jpg
photo_001.jpg
photo_002.jpg

또는:

여행_001.jpg
여행_002.jpg
여행_003.jpg

주요 기능

  • 여러 파일명 일괄 변경
  • 다양한 이름 변경 방식 지원
  • 시작 번호 및 번호 자릿수 설정
  • 변경될 파일명 자동 미리보기
  • 하위 폴더 포함
  • 대소문자 구분 선택
  • 확장자 유지 선택
  • 중복 파일명 검사
  • Windows 금지문자 검사
  • 기존 파일과의 이름 충돌 방지
  • 임시 파일명을 이용한 안전한 일괄 변경

실행:

python renamer.py

참고: 실행 파일(EXE) 버전을 사용하는 경우에는 python 명령을 실행할 필요가 없습니다.
