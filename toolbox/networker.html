플린트 네트워커

버전: 1.1.0

빠른 검사

  1. 프로그램을 실행합니다.
  2. 빠른 검사를 누릅니다.
  3. 검사가 끝나면 하단의 종합 판정을 확인합니다.
  4. 필요한 경우 로그 저장을 눌러 결과를 보관합니다.

빠른 검사는 다음 항목을 확인합니다.

  • 내부 IP
  • 기본 게이트웨이
  • 공유기 Ping 20회
  • Cloudflare 및 Google DNS Ping 20회
  • DNS 조회
  • 패킷 손실과 지연시간
  • 문제 구간 종합 판정

연속 감시

순간적으로 발생하는 인터넷 끊김을 확인할 때 사용합니다.

  1. 감시 간격을 선택합니다.
  2. 연속 감시 시작을 누릅니다.
  3. 끊김이 발생할 때까지 프로그램을 실행해 둡니다.
  4. 검사를 끝낼 때 연속 감시 중지를 누릅니다.

공유기와 외부 인터넷을 계속 검사하며 누적 실패 횟수를 기록합니다.

경로 추적

경로 추적을 누르면 외부 인터넷까지 거치는 구간을 확인할 수 있습니다.

실행 환경

Windows의 ping, route, nslookup, tracert 명령을 사용하므로 Windows 전용입니다.

실행:

python networker.py

참고: 실행 파일(EXE) 버전을 사용하는 경우에는 python 명령을 실행할 필요가 없습니다.
