플린트 문자열 인써터

버전:

사용 방법

  1. 파일 추가를 눌러 작업할 파일을 직접 선택하거나 폴더 추가를 눌러 작업할 폴더를 선택합니다.
  2. 폴더를 선택하면 지원되는 파일을 하위 폴더까지 찾아 목록에 추가합니다.
  3. 삽입할 문자열을 입력합니다.
  4. 문서 맨 위 또는 문서 맨 아래를 선택합니다.
  5. 빈 줄, 백업, 중복 방지 옵션을 확인합니다.
  6. 삽입 실행을 누릅니다.

예시:

<!-- poem -->

# 바람이 된 마음

주요 기능

  • 여러 파일에 동일한 문자열 일괄 삽입
  • 문서 맨 위 또는 맨 아래 삽입
  • 폴더 내 지원 파일 일괄 추가
  • 하위 폴더 포함 검색
  • 삽입 문자열과 본문 사이의 빈 줄 선택
  • 같은 문자열이 이미 있으면 자동 건너뛰기
  • UTF-8, CP949, EUC-KR 인코딩 지원
  • 기존 줄바꿈 형식 유지
  • 원본 파일 자동 백업

지원 확장자:

.txt .md .markdown .html .htm .css .js .py .json .yml .yaml

실행:

python inserter.py

참고: 실행 파일(EXE) 버전을 사용하는 경우에는 python 명령을 실행할 필요가 없습니다.

공구함으로 돌아가기

본 프로그램은 있는 그대로(AS IS) 제공됩니다. 사용으로 인해 발생하는 데이터 손실이나 기타 문제에 대해서는 책임을 지지 않습니다.

중요한 파일은 반드시 백업한 후 사용하시기 바랍니다.
